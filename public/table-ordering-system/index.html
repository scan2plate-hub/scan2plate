Table Ordering System for Restaurants

Scan2Plate is a table ordering system that shows which tables are occupied, what each has ordered and which bills are still open, on one screen. Orders from a guest's phone and from a waiter arrive against the same table, so the running bill is always one bill. Included at ₹499 a month.

Nobody can see the floor at once

Ask a manager mid-service which tables are seated, which are waiting on food and which have asked for the bill, and the answer is assembled by walking around and asking.

That is fine with six tables. At twenty it means a table that finished ten minutes ago is still counted as busy while people queue at the door, and a table that ordered a second round is billed for the first only, because the slip for the second went to the kitchen and nowhere else.

The information exists. It is just spread across a pad, a spike of slips and three people's memory.

How tracking orders by table works

  1. Every table has an identity. Tables are numbered once in settings, and each gets its own QR code if you use QR ordering.
  2. A table becomes occupied when it orders. Whether the order came from a waiter on the POS or from a guest's phone, the table's status changes on the floor view.
  3. Orders accumulate against the table. A second and third round join the same running bill rather than opening new ones, so what is owed is one number at any moment.
  4. The floor view shows the state. Which tables are occupied, which are free, and what each has ordered — without walking the room.
  5. Settling frees the table. Taking payment closes the bill and marks the table available, so whoever is seating guests can see the space immediately.

Why one running bill per table matters

The commonest way a restaurant loses money is not theft. It is a round that was cooked and served but never reached the bill.

It happens when the order and the bill are kept in different places. The kitchen slip is the record of what was made; the bill is assembled separately at the end, from whatever is remembered or still on the spike. A round that arrives during a rush is the one that goes missing.

When every order attaches to the table itself, the bill is not assembled at the end. It already exists, and it already contains everything the kitchen was asked to make.

Seating from the floor view

The practical use of a table view is at the door, not in the accounts.

Whoever is seating guests can see which tables are genuinely free rather than which ones look finished from across the room. A table that settled thirty seconds ago is already showing as available, so the next group is seated while the queue is still short. On a Saturday that is the difference between turning a table twice and turning it once.

Who this suits, and who it does not

It suits you if you seat guests at numbered tables, run more tables than one person can watch, and have ever discovered a round that never made it onto a bill.

It suits you less if you serve entirely by token or counter with no seating you control, such as a takeaway window or a cloud kitchen. The table view is not useful there, and the token flow is the one to use instead.

Questions restaurant owners ask about table ordering

What happens when a table orders a second round?

It joins the same running bill. The table does not open a second order, so the amount owed stays a single figure and the guest settles once. The kitchen still receives the new round as its own ticket, because that is what the kitchen needs.

Can a waiter and a guest both order for the same table?

Yes. An order taken by a waiter on the POS and one placed by a guest from the table QR code both attach to that table. Mixed ordering is normal in practice, and both routes end up on one bill rather than two that have to be merged.

How does a table become free again?

Settling the bill marks it available. That happens as part of taking payment rather than as a separate step someone has to remember, which is what keeps the floor view accurate enough to seat from during a rush.

How many tables can I set up?

Set the number your restaurant actually has in settings, and generate a QR code for each. There is no per-table charge, so adding tables for an outdoor section or a private room costs nothing beyond printing the codes.
