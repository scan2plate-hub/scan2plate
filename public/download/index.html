With the installed Scan2Plate POS app, core billing can continue during temporary network interruptions. Offline bills are stored safely on the device and synchronized when internet connectivity returns.

Installation Help

Windows
  1. Download Scan2Plate Setup.
  2. Run the installer.
  3. Open Scan2Plate.
  4. Login to your restaurant account.
macOS
  1. Download the DMG.
  2. Open the DMG.
  3. Drag Scan2Plate to Applications.
  4. Open the app from Applications. macOS will block the first launch with a security warning (this build isn't yet notarized by Apple, so macOS shows this for any first run — it has not found anything harmful). Go to System Settings → Privacy & Security, scroll down to the message about Scan2Plate, and click Open Anyway. Confirm once more when prompted, then the app opens normally on every launch after that.
  5. Login.
Android
  1. Download the APK.
  2. Allow installation from this source if your device asks.
  3. Install Scan2Plate.
  4. Login.
Linux
  1. Download the AppImage.
  2. Make it executable if needed (chmod +x Scan2Plate.AppImage).
  3. Launch Scan2Plate.
